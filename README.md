> An AI-powered personal portfolio experience, built as a generative intelligence showcase rather than a conventional open-source project.

**Ishaan Koradia** presents a polished, interactive website that blends portfolio storytelling with a conversational AI assistant. It is designed to feel like a living showcase of modern GenAI engineering—where presentation, persona, and intelligent interaction are all part of the experience.

### The Vision
This website is not just a static resume; it is a generative gateway into Ishaan's capabilities. The platform combines a sleek, responsive front end with an MCP-backed AI chat assistant to deliver a seamless, narrative-rich visitor experience. The goal is to let users explore skills, projects, and background through both visual storytelling and intelligent conversation.

---

### ✦ Engineering Highlights
- **AI-first portfolio experience:** The site features an MCP-powered chatbot that interprets visitor questions and responds with contextual knowledge about Ishaan’s skills, education, and projects.
- **Generative conversational interface:** Visitors can query the website naturally, and the backend routes those requests through a robust Gemini-powered AI orchestration layer.
- **Dynamic personalization:** Typed text animations, particle-driven motion, and content sections adapt to user engagement to create a premium, immersive feel.
- **Model routing resilience:** The backend maintains a multi-model execution strategy using a prioritized Gemini model list, enabling smooth inference even during higher load or API volatility.
- **Focused knowledge boundary:** The assistant is explicitly constrained to answer only questions about Ishaan Koradia, ensuring the experience remains tight, relevant, and professional.

### ✦ Technical Architecture
**Frontend**
- **HTML5/CSS3:** Responsive layouts and polished component styling
- **JavaScript + jQuery:** Interactive animation controls and UI transitions
- **Typed.js:** Real-time typing effects for the hero section
- **Particles.js:** Subtle background motion that enhances aesthetic depth

**Backend & AI**
- **FastAPI:** Lightweight Python API for chatbot and site interactions
- **MCP (Model Context Protocol):** Native AI integration layer powering tool-aware responses
- **RAG (Retrieval-Augmented Generation):** Retrieves appropriate information from given resources and files
- **Gemini API:** Multi-model content generation and fallback routing
- **OpenAI/Open-source inference:** Engineered for generative dialogue and contextual answering

### Why this feels like GenAI
This project is intentionally framed as a generative AI showcase: the website is a persona-driven experience built around an intelligent assistant. It highlights how conversational AI can transform a portfolio into an interactive product, with prompt-governed reasoning, conditional model selection, and a strict knowledge boundary centered on Ishaan!
